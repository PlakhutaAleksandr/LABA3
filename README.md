# Домашнее задание к работе 3

## Условие задач

Написать и отладить программу вычисления площади и периметра прямоугольного треугольника по 2-м его сторонам.

## 1. Алгоритм и блок-схема.

### Алгоритм

1. **Начало**
2. **Объявление и инициализация переменных:**
   - `double a = 0.0` — первый катет треугольника.
   - `double b = 0.0` — второй катет треугольника.
   - `double c = 0.0` — гипотенуза.
   - `double area = 0.0` — площадь треугольника.
   - `double perimeter = 0.0` — периметр треугольника.
3. **Ввод исходных данных:**
   - Вывести приглашение ко вводу.
   - Считать значения катетов `a` и `b` с помощью функции `scanf`.
4. **Вычисления:**
   - Вычислить гипотенузу по теореме Пифагора: c = sqrt(a * a + b * b).
   - Вычислить площадь: area = 0.5 * a * b
   - Вычислить периметр: perimeter = a + b + c.
5. **Вывод результатов:**
   - Вывести на экран заголовок результатов.
   - Вывести значения гипотенузы, площади и периметра с точностью до двух знаков после запятой (`%.2lf`).
6. **Конец**

## 2. Реализация программы

#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>
#include <stdlib.h>
#include <math.h>

int main() {
    setlocale(LC_ALL, "Russian");

    double a = 0.0;
    double b = 0.0;
    double c = 0.0;
    double area = 0.0;
    double perimeter = 0.0;

    printf("Введите два катета a и b через пробел: ");
    scanf("%lf %lf", &a, &b);

    c = sqrt(a * a + b * b);
    area = 0.5 * a * b;
    perimeter = a + b + c;

    printf("\n--- Результаты ---\n");
    printf("Гипотенуза c = %.2lf\n", c);
    printf("Площадь = %.2lf\n", area);
    printf("Периметр = %.2lf\n", perimeter);


    return 0;
}
